# Clash Royale Meta Advisor

A web application providing real-time meta insights, deck analytics and community-driven statistics for Clash Royale.

## Getting Started

```bash
npm install
npm run dev       # start local development server
```

## Build

```bash
npm run build     # bundles to /dist
```

Deploy the contents of the `dist` folder to any static host (Vercel, Netlify, GitHub Pages, etc.).

---

Made with Vite + React + TypeScript and Tailwind CSS.
